# CampusPool agent instructions for Claude-based coding agents

**Read AGENTS.md at the repository root first.** It is the authoritative multi-agent working agreement.

Then read docs/agents/README.md, docs/agents/STATUS.md, docs/agents/NEXT_STEPS.md and docs/agents/ARCHITECTURE_MAP.md. Before coding, create a distinct task file from docs/agents/tasks/TEMPLATE.md. During work, record progress and test evidence; before PR or merge update STATUS, NEXT_STEPS and the task handoff.

Never assume an existing GitHub feature is deployed. Never expose secrets or perform unapproved production operations. Re-read latest main when resolving documentation conflicts.

This file delegates all policy details to AGENTS.md to avoid conflicting rules.
